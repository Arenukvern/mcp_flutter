# E2E scenarios

When a flow should run in **CI** or on a schedule, promote it from chat to **checked-in Dart** using **`flutter_mcp_harness`**.

![Instrumented tier: make drive-flutter-chrome (ToolkitDriver on showcase/flutter_demo)](../assets/gifs/harness-flutter.gif)

![Browser tier: make drive-web (CdpDriver on showcase/web_demo)](../assets/gifs/harness-web.gif)

## Shape

1. Build or launch the app (`MacosAppTarget`, web target, etc.).
2. Attach **`ToolkitDriver`** to the VM service.
3. Observe → act → assert in Dart.
4. `stop()` in `finally` with a non-zero exit on failure.
