# CI and scripts

Use the **CLI** when you want JSON on stdout, exit codes, and no MCP client in the loop. A recorded `exec` example lives in the [quickstart](../quickstart.mdx#one-shot-cli-no-mcp-chat).

## Preflight

```bash
flutter-mcp-toolkit doctor --json
flutter-mcp-toolkit validate-runtime --target "$VM_WS_URI"
```

`validate-runtime` exercises extensions, snapshot, and capture tiers ([CLI reference](../reference/cli.mdx)).

## One-shot commands

```bash
flutter-mcp-toolkit exec --name semantic_snapshot --args '{"connection":{"uri":"'"$VM_WS_URI"'"}}'
```

## Safe writes

`snapshot create` and `bundle create` support `--check`, `--diff`, `--backup`, and `--no-overwrite` for review-before-write workflows.
