## 🧭 Router

### North Star impact check

Use when a change might move charter, ownership, or boundaries — not for every typo.

| `north_star_impact` | Meaning | Route |
| --- | --- | --- |
| `none` | Local fix; no stewardship meaning. | Native gate (`make` / `dart test`). |
| `applies` | Uses current North Star paths. | Implement + run focused checks. |
| `clarifies` | Explains an existing boundary. | Update FAQ row, skill, or map link. |
| `sub_star` | Package-local boundary (harness vs toolkit). | Package FAQ pair + link to root [NORTH_STAR](NORTH_STAR.mdx). |
| `amends` | Changes what we own, refuse, or ship. | ADR + [NORTH_STAR](NORTH_STAR.mdx) diff before merge. |
| `conflicts` | Pulls toward a different center. | Stop; ADR or reject. |

## 🔌 App wiring desk

```dart
// pubspec: mcp_toolkit (debug dependency)
import 'package:mcp_toolkit/mcp_toolkit.dart';

void main() {
  WidgetsFlutterBinding.ensureInitialized();
  MCPToolkitBinding.instance
    ..initialize()
    ..initializeFlutterToolkit(); // built-in Flutter toolkit entries
  runApp(const MyApp());
}
```

Registered entries beyond the built-ins go through `addEntries`; hosts that want the zone-guarded lifecycle use `bootstrapFlutter`.

Deep dive: [App setup](/install/app-setup) · [Custom tools](/use-cases/custom-tools) · package [mcp_toolkit/DX_FAQ](../mcp_toolkit/DX_FAQ.mdx).

## 🕹️ Drive desk

```text
fmtk exec --name status --args '{}'                    # connectivity smoke
fmtk batch --steps '[{"name":"semantic_snapshot"},
  {"name":"tap_widget","args":{"ref":"s_0"}}]'     # one session: observe, then act
```

Refs are scoped to the most recent `semantic_snapshot` in the same session, so pair snapshot and action inside one `batch` (or one MCP session) rather than across separate `exec` runs.

Use cases: [Drive the UI](/use-cases/drive-the-ui) · [CLI](/reference/cli).

## 📜 ADR desk

- Write new ADRs under `decisions/`; mirror with `rsync -a --delete decisions/ docs/decisions/`.
- Index: [decisions/index](/decisions/index) — **0009** reserved/unused.
- Format: `- **Status:** Accepted (YYYY-MM-DD)` at top of each ADR.

- Ethics/boundaries live in North Star — not a separate doc.
