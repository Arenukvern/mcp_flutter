# Docker and MCP Registry (optional)

Docker is **optional**. The primary install path is the native server binary —
via [install.sh](../../install.sh), a client marketplace, or the **`.mcpb`
bundle** attached to every GitHub release (Claude Desktop and other MCPB-aware
clients install `flutter-mcp-toolkit.mcpb` directly; see
[platforms](./platforms.mdx)). Use Docker when your MCP host prefers
containerized servers, or on hosts without a native build (for example Intel
macOS, which runs the `linux/amd64` image under Docker Desktop).

## Official registry entry

Published on the [MCP Registry](https://registry.modelcontextprotocol.io) as **`io.github.Arenukvern/flutter-mcp-toolkit`**.

Image coordinates (tag matches repo `VERSION`, currently **8.0.0**{/* x-release-please-version */} — always pin the tag you validated):

```text
ghcr.io/arenukvern/flutter-mcp-toolkit:<VERSION>
```

Example:

```bash
docker pull ghcr.io/arenukvern/flutter-mcp-toolkit:8.0.0 # x-release-please-version
```

See [`mcp_server_dart/server.json`](../../mcp_server_dart/server.json) for the exact identifiers on your train (OCI image first, MCPB bundle second).

## MCP host config (Docker Desktop)

The image defaults to `--dart-vm-host=host.docker.internal`, which Docker
Desktop (macOS/Windows) resolves to your host — no extra networking flags:

```json
{
  "mcpServers": {
    "flutter-mcp-toolkit": {
      "command": "docker",
      "args": [
        "run",
        "-i",
        "--rm",
        "ghcr.io/arenukvern/flutter-mcp-toolkit:8.0.0" // x-release-please-version
      ]
    }
  }
}
```

Replace the image tag with your validated release version (see repo `VERSION` or `x-release-please-version` markers in this doc).

Your Flutter app still runs **outside** the container in debug mode with `mcp_toolkit` initialized; the container reaches its **Dart VM service** through `host.docker.internal`.

### Linux note

Plain Linux (no Docker Desktop) does not resolve `host.docker.internal`. Use
`--network=host` and target localhost:

```json
"args": [
  "run", "-i", "--rm", "--network=host",
  "ghcr.io/arenukvern/flutter-mcp-toolkit:8.0.0", // x-release-please-version
  "--dart-vm-host=localhost"
]
```

## Build locally

Maintainers and contributors:

```bash
docker build --platform linux/amd64 \
  -f mcp_server_dart/Dockerfile.registry \
  -t flutter-mcp-toolkit-local .
```

More detail: [MCP Registry publish runbook](../contributing/mcp_registry_publish_runbook.mdx) and [`mcp_server_dart/DOCKER.md`](../../mcp_server_dart/DOCKER.md).
