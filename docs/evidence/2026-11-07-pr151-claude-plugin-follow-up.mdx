## Goals (updated after review)

2. Targeted Claude manifest validation with path containment + repo-policy messaging.
3. Single owner for skill asset bot regen (`release_pr_sync_skills`); shared `release-pr-automation` concurrency; post-push `skill-assets-post-sync` status on exact bot SHA.
4. release-please-compatible contributor credit (not stranded `Unreleased`).

## Key Design Decisions

| Decision | Rationale |
|----------|-----------|
| Remove `workflow_run` from `skill-assets-drift` | Review: stale `head_sha`, wrong attach context, privileged execution of PR head on base token. |
| Skill assets only in `release_pr_sync_skills` | Avoid dual writers + race with version sync; `release_pr_sync_versions` runs `sync_version.sh` only. |
| Post-sync idempotence + `skill-assets-post-sync` status | Documents bot SHA verification without claiming to replace required workflow check when `GITHUB_TOKEN` push does not re-fire PR workflows. |
| `fix(plugin):` empty commit for credit | release-please on `main` adds subject line to [#154](https://github.com/Arenukvern/mcp_flutter/pull/154) `7.0.2` Bug Fixes when follow-up merges. |
| Path policy `./` + no `..`/absolute | Repository packaging contract; errors labeled vs Claude upstream hints. |
